# VidSnap ⚡

A modern, lightning-fast, and elegant web application for downloading high-definition videos and extracting audio from popular social media platforms including YouTube, TikTok, Instagram, Twitter/X, Pinterest, and Reddit.

![VidSnap Preview](public/next.svg)

## ✨ Features

- 🎯 **Multi-Platform Support**: Effortlessly download from YouTube, TikTok, Instagram, Twitter (X), Pinterest, and Reddit.
- ⚡ **High-Speed Extraction**: Fast metadata fetching and real-time streaming directly in your browser.
- 🎬 **Quality Selection**: Choose from 1080p, 720p, 480p, or high-bitrate MP3 audio extraction.
- 💎 **Modern UI/UX**: Built with Next.js 16 (App Router), Tailwind CSS v4, Lucide icons, glassmorphism, and responsive design.
- 🔒 **Privacy First**: No tracking, no mandatory accounts, direct download links.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed on your machine
- npm, yarn, pnpm, or bun

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Anupam890/vidFlow.git
cd vidflow
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router & Turbopack)
- **UI & Styling**: [Tailwind CSS v4](https://tailwindcss.com/), [Lucide React](https://lucide.dev/)
- **Language**: TypeScript
